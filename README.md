### Category
- Metadata — Information about the website, browser, and detected technologies.
- Runtime — Current execution state of the page.
- Network — Requests, responses, transferred data, and network activity.
- Memory — JavaScript heap usage and memory-related metrics.
- Performance — Load timings, rendering metrics, and user-perceived performance.

| Category    | Metrics                                                  |
| ----------- | ---------------------------------------------------------------- |
| Runtime     | DOM nodes, cookies, localStorage, sessionStorage, history length |
| Network     | Request count, resource types, bytes transferred, request rate   |
| Memory      | JS heap used, heap total, heap limit                             |
| Metadata    | URL, protocol, framework, libraries, title, language             |
| Performance | FCP, LCP, DOMContentLoaded, Load Event, FPS                      |
